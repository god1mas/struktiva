# Product Requirements

## Product direction

Struktiva is for university students learning Data Structures. It is not only a collection of reading material: it helps learners understand internal operations through synchronized, step-by-step visualization.

The canonical learning journey is:

`Concept -> Interactive Simulation -> Explanation -> Micro Challenge -> Practice -> Quiz`

## MVP scope

Modules: Array, Linked List, Stack, Queue, Searching, and Sorting.

The primary programming language is C++. Code views support C++ and pseudocode.

Guests can use Learn, Visualize, Practice, Challenge, and Quiz. Logged-in users have the same capabilities, plus persisted learning progress and quiz history. MVP progress consists of lesson completion, module progress, and quiz results.

The interface is optimized for desktop and remains usable on mobile.

## Out of scope

- AI Tutor
- Executing or compiling user-provided C++
- Code Playground
- Tree, Graph, Heap, and Hash Table modules
- Gamification and leaderboards
- CMS and teacher dashboard
